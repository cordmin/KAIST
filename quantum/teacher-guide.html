【탐구 1】 분자 속 전자와 지수 폭발 예시 답안

물질명 화학식 전자 수 ($N$) 계산해야 할 상태 수 ($2^N$) 일반 슈퍼컴퓨터의 계산 소요 시간
수소 원자 $H$ 1개 $2^1 = 2$ 가지 0.000001초 (즉시 계산)
물 분자 $H_2O$ 10개 $2^{10} = 1,024$ 가지 약 0.001초 (즉시 계산)
카페인 분자 $C_8H_{10}N_4O_2$ 102개 $2^{102} \approx 10^{30}$ 가지 수백 년 이상 소요 (지구 모든 모래알 $10^{23}$개 초과!)
페니실린(항생제) $C_{16}H_{18}N_2O_4S$ 약 280개 $2^{280} \approx 10^{84}$ 가지 우주 나이(138억 년) 동안 계산해도 불가 (우주 전체 원자 수 $10^{80}$개 초과!)

2. O / X 퀴즈 정답 및 해설

(1) O : 양자역학에 의해 전자들이 취할 수 있는 스핀 조합은 전자가 1개 추가될 때마다 2배씩 기하급수적으로 폭발합니다.
(2) X : 계산 상태 수($10^{84}$가지)가 관측 가능한 우주 전체 원자 수($10^{80}$개)보다 훨씬 많아 슈퍼컴퓨터로 영원히 계산할 수 없습니다.
(3) O : 미시 세계의 전자 스핀 조합은 거시 세계 우주 원자 총수보다 훨씬 커지는 역설적 규모를 갖습니다.

3. 서술형 문항 모범 답안

모범 답안: 분자 속 전자가 1개 늘어날 때마다 계산해야 하는 양자역학적 상태의 수가 2배씩 곱해지는 '지수 폭발($2^N$)'이 발생하기 때문입니다. 전자가 100개만 넘어가도 조합의 수가 지구상 모든 모래알의 수($10^{23}$)나 전 우주의 모든 원자 수($10^{80}$)를 아득히 뛰어넘어, 현존하는 가장 강력한 슈퍼컴퓨터로도 화학 분자의 전자 구름을 계산하는 것이 물리적으로 불가능합니다.

【탐구 2】 동전 팽이 실험과 양자 중첩 예시 답안

비교 항목 고전 비트 (Bit) 양자 큐비트 (Qubit)
동전 비유 바닥에 가만히 누워 있는 동전 책상 위에서 팽이처럼 빠르게 도는 동전
정보의 표현 0 또는 1 중 ( 단 1개만 ) 0과 1 ( 둘 다 동시 공존(중첩) )
10개 사용 시 길 탐색 1,024개 길 중 ( 1개씩 순서대로 ) 1,024개 길 ( 1,024개 길 동시 탐색(초병렬) )

2. O / X 퀴즈 정답 및 해설

(1) O : 회전하는 동안 동전은 앞면(1)과 뒷면(0)이 확률적으로 뒤섞여 공존하는 상태(중첩)입니다.
(2) X : 일반 컴퓨터는 한 번에 하나의 길만 시도하는 직렬 순차 탐색을 하므로 갈래가 많아지면 극도로 느려집니다.
(3) O : 큐비트의 중첩과 얽힘 덕분에 $2^N$개의 모든 상태를 단 1회의 연산 단계에서 동시에 검사할 수 있습니다.

3. 서술형 문항 모범 답안

모범 답안: 일반 컴퓨터(비트)는 미로를 탐색할 때 한 사람이 한 갈래 길씩 끝까지 가보고 벽에 막히면 되돌아 나오는 '순차 탐색' 방식입니다. 반면 양자 컴퓨터(큐비트)는 중첩의 성질을 이용하여 1,024명의 분신이 모든 갈래 길을 '동시에 단 한 번에' 쏟아져 들어가서 출구를 즉각 발견하는 '동시 병렬 처리' 방식입니다.

【탐구 3】 양자-고전 하이브리드 VQE 알고리즘 예시 답안

1. 문항 예시 답안

자연계의 모든 화학 분자는 에너지가 가장 ( 낮은 ) 최저 ( 바닥 상태 (Ground State) )를 찾아 결합합니다.

2. 순서도 예시 답안

[ 1단계: 양자 컴퓨터 ] 큐비트 중첩으로 복잡한 분자의 현재 ( 에너지 값 ) 계산
⬇ 수치 전달
[ 2단계: 일반 컴퓨터 ] 골짜기 바닥으로 내려가도록 결합 각도와 거리를 ( 미세 조정(최적화) )
⬇ 반복(피드백 루프)
[ 3단계: 목표 달성 ] 골짜기 최저 바닥 상태(-1.137 a.u.) 도달! → 가장 안정한 신물질 분자 구조 완성!

3. O / X 퀴즈 정답 및 해설

(1) X : 현재의 양자 컴퓨터(NISQ)는 노이즈가 있어 일반 컴퓨터와의 하이브리드 협동(VQE)이 실용화의 핵심입니다.
(2) O : 양자 컴퓨터는 지수 폭발이 일어나는 분자 상태 에너지만 계산하고, 경로를 찾는 네비게이션은 일반 컴퓨터가 분담합니다.
(3) O : 분자는 에너지가 가장 낮을 때 결합이 가장 안정해지므로 골짜기 최저점(바닥 상태)을 찾는 것이 분자 설계의 최종 목표입니다.

2. O / X 퀴즈 정답 및 해설

(1) O : 비커 없는 '인실리코(In-silico)' 양자 화학 시뮬레이션으로 실험실 폐기물 없이 신물질을 스크리닝할 수 있습니다.
(2) X : 하버-보슈 공정은 엄청난 화석연료와 전력을 소모하여 전 세계 온실가스의 주요 배출원으로 꼽혀 상온 대체 기술이 시급합니다.
(3) O : 분자 후보 물질 수백만 개 중 가장 결합 에너지가 낮은 최적 구조를 양자 컴퓨터로 즉시 선별하여 R&D 기간을 획기적으로 줄입니다.

지도상 유의점 및 수업 지도 팁

1. 학생 오개념 지도 요령: "양자 컴퓨터가 나오면 모든 일반 컴퓨터가 사라지나요?"
학생들은 양자 컴퓨터가 유튜브 시청이나 게임, 워드 프로세서까지 모두 대체할 것이라고 오해하기 쉽습니다. 양자 컴퓨터는 일상적인 사무 작업용이 아니라, '분자 시뮬레이션, 거대 조합 최적화, 암호 해독' 등 특수한 병렬 연산에만 특화된 장치이며, 미래에도 일반 컴퓨터와 양자 컴퓨터가 서로 협력(VQE처럼)하여 공존함을 명확히 지도합니다.
2. 동전 팽이 조작 실험 팁
학생들이 동전을 돌릴 때 책상 밑으로 떨어지지 않도록 책받침이나 평평한 트레이 위에서 돌리도록 안내합니다. "동전이 돌고 있을 때 여러분은 앞면이라고 단정할 수 있나요, 뒷면이라고 단정할 수 있나요?"라는 발문을 통해 '측정하기 전에는 0과 1이 공존하는 중첩 상태'임을 체감하도록 유도합니다.
3. 가상실험실(lab.html) 연계 안내
2차시 수업에서는 [블록 구 큐비트 시뮬레이터]를 통해 0과 1의 확률을 조작해보고, 3차시 수업에서는 [VQE 에너지 최적화 시뮬레이터]를 조작하여 두 원자 사이의 거리가 좁아졌다가 넓어지며 에너지가 가장 낮은 골짜기 바닥에 쏙 들어가는 장면을 직관적으로 확인하도록 지도합니다.
