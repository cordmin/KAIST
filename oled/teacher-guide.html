4. 교사 도움 자료: 탐구 활동 모범답안 및 지도 가이드

【탐구 1】 자외선 형광 물질 관찰 예시 답안

1. 각 물질의 관찰 결과 예시표

실험 물질 포함된 핵심 분자 일반 조명 아래 색상 자외선을 쬐었을 때 색상 (예시 답안)
토닉워터 퀴닌 (Quinine) 투명한 무색 눈부신 푸른색 (Blue) 형광
비타민 음료 리보플라빈 (비타민 $B_2$) 노란색 밝은 형광 연두색 / 황록색
올리브유 엽록소 (Chlorophyll) 연한 초록색 / 노란색 선명한 붉은색 (Red) 형광
천원권 지폐 형광 인쇄 섬유 일반 인쇄만 보임 숨겨진 형광 보안 섬유 발광

2. O / X 퀴즈 정답 및 해설

(1) O : 빛은 파장이 짧을수록 진동수가 높고 광자당 에너지가 큽니다. 자외선(300~400nm)이 가시광선(400~700nm)보다 에너지가 큽니다.
(2) X : 에너지 보존 법칙에 의해 흡수한 자외선 에너지는 방출된 형광빛 에너지와 발생한 열에너지의 합과 같으므로, 흡수한 자외선이 항상 더 큽니다.
(3) O : 흡수된 자외선의 높은 에너지는 일부 열로 빠져나가고 남은 에너지가 형광빛으로 방출됩니다.

3. 서술형 문항 모범 답안

모범 답안: 자외선을 흡수한 물질 속 분자가 일부 에너지를 열로 먼저 방출하고, 남은 에너지를 파장이 더 길고 에너지가 낮은 가시광선(형광빛)으로 방출하기 때문입니다. (자외선 에너지 = 형광빛 에너지 + 열에너지)

【탐구 2】 전자의 에너지 전달 예시 답안

단계전자의 상태 변화 및 에너지 전환 (예시 답안)
1단계 원자 속 전자가 ( 자외선 ) 에너지를 흡수하여 에너지가 높아진 들뜬 상태가 된다.
2단계 전자가 주변 원자들과 부딪히고 진동하며 일부 에너지를 ( 열 ) 형태로 방출한다.
3단계 전자가 남은 에너지를 ( 형광빛 )으로 방출하며 원래의 안정한 바닥 상태로 되돌아온다.

2. O / X 퀴즈 정답 및 해설

(1) O : 전자는 외부 에너지를 흡수하면 높은 에너지 준위인 들뜬 상태로 도약합니다.
(2) X : 들뜬 상태는 매우 불안정하므로 전자는 즉시 열과 빛을 방출하고 가장 안정한 바닥 상태로 되돌아옵니다.
(3) O : 에너지는 새롭게 생기거나 소멸하지 않고 형태만 전환되므로 흡수한 총에너지는 방출된 열과 빛의 합과 일치합니다.

3. 에너지 보존 관계식 모범 답안

[ 자외선 에너지 ] = [ 형광빛 에너지 ] + [ 열에너지 ]

【탐구 3】 스마트폰의 배터리 낭비 예시 답안

구분 빛을 내는 분자 열을 내는 분자
에너지 방출 형태 유용한 ( 화면 빛 ) 기기 낭비인 ( 기기 발열 )
전기 공급 시 생성 비율 25 % (4개 중 1개) 75 % (4개 중 3개)

2. O / X 퀴즈 정답 및 해설

(1) X : 배터리 전기가 공급되면 1:3 자연 법칙에 의해 유용한 빛을 내는 분자는 25%에 불과하며 75%는 빛을 내지 못합니다.
(2) O : 75%에 해당하는 분자는 빛을 내지 못하고 강한 진동 에너지로 바뀌어 기기 발열로 전부 버려집니다.
(3) O : 낭비된 열은 배터리 조기 방전의 주범이며, 높은 온도로 인해 유기 분자가 파괴되면서 화면 번인(잔상) 현상을 유발합니다.

3. 서술형 문항 모범 답안

모범 답안: 스마트폰 배터리 전기가 공급되면 화면 속 분자의 75%가 빛을 내지 못하고 발열로 전부 낭비됩니다. 이로 인해 배터리가 빠르게 닳아 사용 시간이 단축되고, 기기가 뜨거워지며, 지속적인 열 때문에 발광 분자가 손상되어 화면 수명이 줄어들고 잔상(번인)이 발생하는 심각한 문제가 일어납니다.

【탐구 4】 차세대 청색 OLED 분자 설계 기획서 예시 답안

모둠명 / 과제명 청색 OLED 연구 모둠 작성자(모둠원) 김청색 외 3명
해결할 과제 높은 에너지로 인해 쉽게 분해되는 청색 발광 분자의 열화(번인) 방지 및 발광 효율 100% 달성
청색 분자 구조
스케치 및 설명		 단단한 다환 고리 구조로 원자 결합을 강력하게 붙잡아 진동에 의한 열 손실을 억제하고 분자 깨짐을 방지함.
75% 구출 핵심 전략 KAIST 초고속 에너지 전환 기술 적용:
75%의 에너지가 열로 완전히 식어버리기 전에, 에너지가 높은 상태에서 빛을 낼 수 있는 상태로 초고속 방향 전환시키는 기술을 적용하여 열로 버려지던 75%의 에너지를 유용한 빛으로 전환함.
기대 효과 스마트폰 배터리 사용 시간 2배 증대, 잔상 없는 초고화질 OLED 상용화, 에너지 절감 기여.

2. O / X 퀴즈 정답 및 해설

(1) O : 파란색 빛은 가시광선 중 파장이 가장 짧고 에너지가 가장 높아 결합 손상이 잦아 OLED의 난제로 꼽힙니다.
(2) X : 열로 완전히 식어 주변으로 흩어지면 다시 모으는 것이 불가능하므로, 열로 식기 전에 빛을 내는 상태로 초고속 전환시켜야 합니다.
(3) O : 25%의 형광 빛에 더해 75%의 버려지는 에너지를 빛으로 전환하면 이론상 100% 내부 발광 효율을 달성할 수 있습니다.

지도상 유의점 및 실험 지도 팁

1. 학생 오개념 지도 요령: "형광과 야광(인광)은 같은 건가요?"
학생들은 어둠 속에서 빛나는 현상을 모두 '야광'으로 통칭하는 경우가 많습니다. 형광펜(조명을 끄면 1억분의 1초 만에 즉시 꺼짐)과 야광 스티커(불을 꺼도 에너지를 천천히 방출하여 수 시간 동안 지속됨)의 차이를 실물로 비교하게 하고, 빛을 즉시 방출하는 상태와 그렇지 못한 상태의 차이를 직관적으로 체감하도록 지도합니다.
2. 시약 및 준비물 선택 팁
• 토닉워터: 마트에서 판매하는 토닉워터 중 원재료명에 '퀴닌(Quinine)' 향 또는 성분이 표기된 제품을 구매해야 강력한 청색 형광이 나타납니다.
• 비타민 음료: 비타민 B2(리보플라빈)가 함유된 비타민 음료(예: 비타500, 오로나민C 등)를 사용하면 눈부신 황록색 형광을 쉽게 관찰할 수 있습니다.
• 올리브유: 엑스트라 버진 올리브유일수록 엽록소가 풍부하여 붉은색 형광이 선명합니다.
3. 가상실험실(lab.html) 연계 안내
실제 분자 레벨의 전자 전이는 눈으로 볼 수 없으므로, 학생들이 직접 파장 슬라이더를 조작하며 전자가 3층으로 점프했다가 열을 흘리고 형광을 내며 떨어지는 [가상실험실(lab.html)]을 10분간 적극 활용하도록 안내합니다.
