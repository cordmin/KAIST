4. 교사 도움 자료: 탐구 활동 모범답안 및 지도 가이드

【탐구 1】 자외선 형광 탐정단 예시 답안

1. 각 물질의 관찰 결과 예시표

실험 물질 포함된 핵심 분자 일반 조명 아래 색상 자외선(UV-A) 조사 시 색상 (예시 답안)
토닉워터 퀴닌 (Quinine) 투명한 무색 눈부신 푸른색 (Blue) 형광
비타민 음료 리보플라빈 (비타민 $B_2$) 노란색 밝은 형광 연두색 / 황록색
올리브유 엽록소 (Chlorophyll) 연한 초록색 / 노란색 선명한 붉은색 (Red) 형광
대한민국 지폐 형광 인쇄 섬유 일반 인쇄만 보임 숨겨진 형광 보안 섬유 발광 (주황/청록)

2. 파장과 에너지 관계

☞ 모범 답안: 자외선(300~400nm)이 가시광선(400~700nm)보다 파장이 짧고 에너지가 더 크다. (빛의 파장이 짧을수록 광자의 에너지는 크다.)

3. 형광 현상과 에너지 차이의 행방

☞ 모범 답안: 물질 속 분자가 센 에너지의 자외선을 흡수하여 전자가 들뜬 상태로 점프한 뒤, 분자 진동을 통해 일부 에너지를 '열'로 잃어버립니다. 그 후 남은 에너지만을 파장이 더 길고 에너지가 순한 '가시광선(형광)' 빛으로 방출하기 때문에 알록달록한 빛이 나옵니다. 들어간 자외선과 나온 형광 빛의 에너지 차이는 분자가 떨리며 주변에 방출한 열에너지로 전환되었습니다. (스토크스 이동 및 에너지 보존 법칙)

【탐구 2】 꼬마 전자의 트램펄린 점프 예시 답안

단계전자의 상태 변화 및 에너지 전환 (예시 답안)
1단계: 흡수 바닥 상태(1층)의 전자가 ( 자외선(높은 에너지) ) 에너지를 먹고 ( 들뜬 ) 상태(3층)로 높이 점프한다.
2단계: 진동 3층이 너무 불안정하여 전자가 부르르 떨며(분자 진동) 에너지를 ( 열 ) 에너지 형태로 잃어버린다.
3단계: 방출 남은 에너지를 알록달록한 ( 가시광선 형광 ) 빛으로 번쩍 뿜어내며 바닥 상태로 사뿐히 착지한다.

2. 에너지 보존 관계식

☞ [ 흡수한 자외선 에너지 ] = [ 방출된 형광빛 에너지 ] + [ 흘린 열에너지 ]

【탐구 3】 팽이 스핀과 스마트폰 OLED의 75% 배터리 도둑 예시 답안

구분 단일항 (Singlet) 삼중항 (Triplet)
전자 팽이 회전 방향 서로 ( 마주보고 ) 회전 (↑↓) 서로 ( 나란히 ) 회전 (↑↑)
방출되는 빛의 종류 형광 (Fluorescence) 인광 (Phosphorescence)
빛을 내뿜는 속도 1억 분의 1초 만에 ( 즉시 방출 ) 비상문이 잠겨 ( 갇혀서 천천히 방출 )
전기 주입 시 생성 확률 25 % (4개 중 1개) 75 % (4개 중 3개)

2. 스마트폰 발열과 배터리 손실 이유

☞ 모범 답안: 스마트폰 배터리의 전류를 유기 발광 분자에 직접 넣으면 양자 통계 법칙에 의해 빛을 내는 단일항은 단 25%만 생성되고, 비상문이 잠겨 빛을 내지 못하는 삼중항이 무려 75%나 생성됩니다. 상온의 스마트폰 디스플레이에서 75%의 삼중항 전자는 빛을 내지 못한 채 에너지를 모조리 열로 뿜어내며 바닥으로 떨어지므로, 배터리 전력의 75%가 낭비되고 스마트폰이 뜨겁게 달아오릅니다.

【탐구 4】 차세대 청색 OLED 분자 디자이너 프로젝트 예시 산출물

스타트업 회사명 블루 엑시톤 테크 (Blue Exciton Tech) 대표 분자 디자이너 김미래 학생 (신소재 화학자)
나만의 청색 분자
아이디어 및 구조		 • 붕소(B)와 질소(N)를 육각형 벤젠 고리 내부에 단단하게 고정한 다중 공명 구조 고안
• 분자가 자유롭게 흔들리며 결합이 끊어지는 것을 막기 위해 단단한 고리형 브릿지를 추가하여 진동 에너지 손실을 최소화함.
75% 구출 메커니즘
적용 방안		 [핫 엑시톤(Hot Exciton) 우회로 선택]
☞ 원리: 삼중항 전자가 1층(T1)에 갇혀 열을 내기 전에, 에너지가 높은 2층 삼중항(T2) 옥상에서 단일항(S1)으로 순식간에 건너가는 '초고속 구름다리(역간교차, RISC)'를 설계함. 이를 통해 버려지던 75%의 전자를 단일항으로 100% 구출하여 눈부신 파란색 형광으로 전환함.
미래 사회 기대 효과 • 청색 OLED의 발광 효율이 4배(25% → 100%)로 향상되어 스마트폰 디스플레이 소비 전력을 획기적으로 절감.
• 열 발생이 급감하여 스마트폰 발열 문제가 해결되고, 청색 화소 수명이 5배 이상 늘어나 영구적인 롤러블/폴더블 화면 상용화 기여.

💡 [지도상 유의점 및 실험 지도 팁]

1. 학생 오개념 지도 요령: "형광과 야광(인광)은 같은 건가요?"
학생들은 어둠 속에서 빛나는 현상을 모두 '야광'으로 통칭하는 경우가 많습니다. 형광펜(조명을 끄면 1억분의 1초 만에 즉시 꺼짐)과 야광 스티커(불을 꺼도 전자가 갇혀 있어 수 시간 동안 지속됨)의 차이를 실물로 비교하게 하고, 이는 전자가 "마주보고 도는가(단일항) vs 나란히 도는가(삼중항)"라는 스핀 규칙 때문에 일어남을 강조하여 지도합니다.
2. 시약 및 준비물 선택 팁
• 토닉워터: 마트에서 판매하는 토닉워터 중 원재료명에 '퀴닌(Quinine)' 향 또는 성분이 표기된 제품을 구매해야 강력한 청색 형광이 나타납니다.
• 비타민 음료: 비타민 B2(리보플라빈)가 함유된 비타민 음료(예: 비타500, 오로나민C 등)를 사용하면 눈부신 황록색 형광을 쉽게 관찰할 수 있습니다.
• 올리브유: 엑스트라 버진 올리브유일수록 엽록소가 풍부하여 붉은색 형광이 선명합니다.
3. 가상실험실(lab.html) 연계 안내
실제 분자 레벨의 전자 전이는 눈으로 볼 수 없으므로, 학생들이 직접 파장 슬라이더를 조작하며 전자가 3층으로 점프했다가 열을 흘리고 형광을 내며 떨어지는 [가상실험실(lab.html)]을 10분간 적극 활용하도록 안내합니다.
